# Repos

> **TL;DR:** Local clones of project repositories — contents are gitignored; use this file as an index and navigation aid for agents.

## Purpose

Clone related source repositories into this folder (e.g. `Repos/Laboratorio_Paradigmas/`). Each clone keeps its own Git history; the **workspace** repository does not track those trees (see root `.gitignore`).

## What belongs here

- Git clones of repos you work on from this workspace.
- Optional notes in this file listing clone paths, remotes, and which lab or task uses each repo.

## What does NOT belong here

- Long-lived team knowledge — use [../Knowledge/AGENTS.md](../Knowledge/AGENTS.md).
- Scratch or generated files — use [../temp/AGENTS.md](../temp/AGENTS.md).

## Conventions

- One subdirectory per clone, named after the repo (kebab-case or matching the remote name).
- After cloning, add a one-line entry under **Indexed clones** below.
